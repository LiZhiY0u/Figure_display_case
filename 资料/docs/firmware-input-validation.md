日期：2026-10-10；基线 ad6bf9f。状态：代码、自动化验证与独立审查完成；用户反馈“测试无误”，第一阶段实机验收通过。此为用户反馈，非代理独立测量，不代表所有极端并发与内存不足场景已覆盖。

## 实现范围

- GamepadInput::State 独立处理 A 键边沿、方向冲突、摇杆滞回、400/150ms 重复计时及断开 Reset。
- UserInput::Event 携带动作、来源、毫秒时间戳；BTstack 占用了 Input 名称，因此使用 UserInput 命名空间。
- InputQueue 固定容量 16、FIFO、零等待；满队列拒绝新事件，DroppedCount 原子计数。此计数可由调试器读取或临时输出，不默认刷串口。
- 手柄、小程序、编码器任务按钮回调、UI 线程的编码器旋转/串口采集共用队列；ISR 未改。
- UI 保留 pending 事件，每轮最多消费一个；Previous/Next/Confirm 映射保持既有 BTN_ID。
- 去掉示例 A/B/X 灯效、震动命令；连接通知、协议、外设引脚与任务配置未改。
- 独立日志默认关闭；开启时打印按钮、十字键和左摇杆，其他模拟量暂未纳入新日志接口。
