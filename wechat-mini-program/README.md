# FigureCase 微信小程序遥控器

## BLE 约定

- 广播名：`FigureCase`
- Service UUID：`0000FF10-0000-1000-8000-00805F9B34FB`
- Write UUID：`0000FF11-0000-1000-8000-00805F9B34FB`

| 按键 | 数据 | 当前 UI 映射 |
|---|---:|---|
| 上 | `0x01` | 上一项 |
| 下 | `0x02` | 下一项 |
| 左 | `0x03` | 上一项 |
| 右 | `0x04` | 下一项 |
| 确定 | `0x05` | 短按确认 |

## 导入

用微信开发者工具导入本目录。`project.config.json` 当前使用测试 AppID；真机调试或发布前，请换成自己的小程序 AppID。
